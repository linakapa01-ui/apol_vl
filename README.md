# Νίκος Βλάχος – εφαρμογή προγράμματος

Εφαρμογή (PWA) στα ελληνικά για ραντεβού, πελατολόγιο, πληρωμές και στατιστικά για
απεντόμωση, μυοκτονία και απολύμανση. Είναι στατική (HTML, CSS, JavaScript χωρίς
εγκατάσταση). Τα δεδομένα αποθηκεύονται τοπικά και, αν ρυθμιστεί, συγχρονίζονται
μεταξύ συσκευών (δες `SETUP_SHARED.md`).

## Εκτέλεση τοπικά

```bash
python3 -m http.server 47213
```

Άνοιξε το http://127.0.0.1:47213/index.html.

## Λειτουργίες

- **Αρχική:** σημερινό πρόγραμμα, ραντεβού που περιμένουν ενημέρωση, κουτί εκκρεμών
  πληρωμών, έτοιμες επαναλήψεις.
- **Εβδομάδα:** Δευτέρα έως Κυριακή κάθετα, με πλοήγηση ανά εβδομάδα, χρέωση ανά όροφο
  και τσεκ για πολυκατοικία, διαμερίσματα, φρεάτια.
- **Πελάτες:** αναζήτηση, φίλτρα κατηγορίας και βαθμολογίας, ιστορικό.
- **Στατιστικά:** έσοδα, κατηγορίες, μετρητά ή κάρτα, ημέρες, ακυρώσεις, βαθμολογίες.
- **Μηνύματα:** έτοιμα και επεξεργάσιμα μηνύματα που ανοίγουν στο SMS του κινητού.
- **Προφίλ:** λογότυπο, κατηγορίες εργασίας, κοινά δεδομένα, ειδοποιήσεις.

## Καταστάσεις ραντεβού

Προγραμματισμένο, Περιμένει ενημέρωση (πέρασε η ώρα), Ολοκληρώθηκε (πληρώθηκε με
μετρητά ή κάρτα), Αναμένεται πληρωμή, Αναβλήθηκε, Ακυρώθηκε (με λόγο).

## Βαθμολογία πελάτη

Ξεκινά από 100. Αφαιρούνται 5 πόντοι για ακύρωση εγκαίρως, 20 για ακύρωση την
τελευταία στιγμή και 35 για μη εμφάνιση. Κακοκαιρία και δικά μας προβλήματα δεν μετράνε.
Από 80 και πάνω Καλός, από 55 Μέτριος, κάτω από 55 Κακός.

## Αρχεία

- `index.html`, `styles.css`: δομή και εμφάνιση
- `util.js`, `store.js`, `domain.js`: βοηθητικά, αποθήκευση και συγχρονισμός, κανόνες
- `views.js`, `sheets.js`, `dashboard.js`, `messages.js`, `main.js`: οθόνες και ενέργειες
- `config.js`, `supabase.sql`, `SETUP_SHARED.md`: κοινή βάση δεδομένων
- `manifest.json`, `assets/`: ρυθμίσεις PWA και λογότυπα
